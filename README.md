# Industrial Monitoring Platform

A full-stack industrial monitoring system for real-time machine and sensor monitoring.

---

## Features

- Real-time sensor monitoring
- Industrial dashboard
- Machine status tracking
- Alert system
- Historical data storage
- WebSocket communication
- Dockerized environment

---

## Tech Stack

### Backend
- Java
- Spring Boot

### Frontend
- Angular

### Database
- PostgreSQL

### DevOps
- Docker
- Docker Compose

---

## Architecture

```txt
Angular Frontend
       |
REST API + WebSockets
       |
Spring Boot Backend
       |
PostgreSQL
```
